# Ruby Arrays Notes

This matches the ideas in `about_arrays.rb`.

Arrays are ordered, zero-indexed objects. `first`, `last`, positive indexes, and
negative indexes are different ways to access elements; `-1` means the last
element.

`push` and `<<` add at the end. `pop` removes and returns the last element.
`unshift` adds at the beginning. `shift` removes and returns the first element.

For slicing rules, see [RUBY_ARRAY_SLICING_CHEAT_SHEET.md](RUBY_ARRAY_SLICING_CHEAT_SHEET.md).
